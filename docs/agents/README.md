## Detailed Agent Specification Template Reference

Every individual agent document strictly adheres to the standard 15-part specification:
- **A. Identity:** Name, ID, category, status, source project, implementation files.
- **B. Purpose:** Core problem solved.
- **C. Responsibilities:** In-scope and out-of-scope boundaries.
- **D. Capabilities:** Verified, partial, and planned capabilities.
- **E. Inputs:** Required and optional context, trigger conditions, upstream dependencies.
- **F. Tools and Integrations:** APIs, connectors, and scripts.
- **G. Processing Logic:** Decision rules, constraints, algorithms.
- **H. Outputs:** Format, schema, examples, downstream consumers.
- **I. Inter-Agent Communication:** Callers, callees, data handoffs.
- **J. Memory and Persistence:** Reads, writes, caching.
- **K. Autonomy and Permissions:** Level A/B/C classification.
- **L. Error Handling:** Edge cases, missing data, timeouts.
- **M. Evaluation:** Test plan and validation checks.
- **N. Limitations:** Known constraints and assumptions.
- **O. Extension Guide:** Instructions for safely extending the agent.
