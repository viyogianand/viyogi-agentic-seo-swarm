### AEO (Answer Engine Optimization)
The practice of formatting content, direct-answer snippets, FAQ accordions, and schema markups so that AI-driven answer engines (such as Google Featured Snippets, Google Assistant, Siri) can directly extract concise answers to user queries.

### GEO (Generative Engine Optimization)
Optimizing digital content, entity associations, and semantic authority so that large language model search systems (Google AI Overviews, Perplexity AI, ChatGPT Search, Microsoft Copilot) cite and recommend the brand as an authoritative source.

### Striking-Distance Keywords
Search queries where a website ranks between **Position 4.0 and Position 20.0** (bottom of page 1 to page 2). These represent the highest ROI optimization opportunities because small improvements in on-page intent alignment or internal link equity can elevate them into high-CTR top-3 positions.

### PAA (People Also Ask)
Dynamic question accordions displayed by Google in search results. The swarm clusters PAA queries to extract real buyer and user questions and injects concise direct-answer blocks beneath matching H2/H3 headers.

### NAP (Name, Address, Phone)
The foundational data trinity for local search. Extreme character-by-character consistency across Google Business Profile, website footers, and local directories is mandatory for local 3-pack dominance.

### Prediction Error Score (PES)
The metric calculated by Forecaster to retrospectively calibrate ranking forecast accuracy over a 28-day window:
$$\text{PES} = \left| \frac{\text{Actual Position} - \text{P50 Target}}{\text{Baseline Position} - \text{P50 Target}} \right|$$
A PES $\le 0.35$ indicates a calibrated model.

### Strategic Memory
A 4-tier Bayesian memory architecture maintained by Archivist that stores:
1. **Level 1:** Grounded Facts (immutable specs, dimensions, certifications).
2. **Level 2:** Empirical Observations (time-series events and SERP shifts).
3. **Level 3:** Causal Learnings (measured takeaways from completed 28-day experiments).
4. **Level 4:** Strategic Rules (codified heuristics that guide future decision trees).

### Zero-Tolerance Verification Gate (Sentinel)
A strict architectural checkpoint where an autonomous agent (Sentinel) possesses non-overrideable veto authority to reject any content draft containing fabricated specifications, unsupported claims, or invalid JSON-LD schemas.
